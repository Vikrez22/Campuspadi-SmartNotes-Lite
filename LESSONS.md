# LESSONS.md

A running log of mistakes, surprises, and fixes encountered while building
this project. Updated at the end of every session per the standing
instruction in `AGENTS.md` §7 — this is part of the definition of done, not
optional cleanup.

**Rule for adding entries:** if a fix required more than one attempt, or
something behaved unexpectedly relative to documentation/assumptions, it goes
here — even if the eventual fix was simple. The value is in the trail, not
just the resolution.

Newest entries at the top.

---

## Template (copy this for each new entry)

```
## [YYYY-MM-DD] <short task description>

**Task:** What were you trying to do?

**What went wrong:** What broke, failed, or behaved unexpectedly?

**Root cause:** Why did it actually happen — not just the symptom.

**Fix applied:** What change resolved it.

**Rule going forward:** One concrete, checkable rule this adds to the
project (this should be specific enough to prevent the same mistake —
"be more careful" is not a rule; "always run X before Y" is).
```
